# Adivina el número

Juego en Python para la terminal: el computador elige un número del 1 al 100 y tú tienes que adivinarlo con pistas de "más alto" o "más bajo".

## Cómo ejecutar
Necesitas Python 3.

```bash
python adivina.py
```

## Lo que aprendí
- Usar la librería `random` para generar números al azar
- Llevar un contador con una variable
- Repetir con `while` hasta cumplir una condición
- Comparar números con `if / elif / else`
